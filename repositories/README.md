# Repositories

## 가이드라인

- 데이터 접근 집중: 데이터베이스와의 상호작용은 모두 Repository 계층에서 처리하며, 쿼리나 ORM 로직을 캡슐화합니다.
- 인터페이스 정의: Repository 인터페이스를 정의하여, 나중에 다른 데이터 소스(예: 메모리, 캐시 등)로 쉽게 전환할 수 있도록 합니다.
- 에러 처리: DB 연결 및 쿼리 실행 중 발생하는 에러에 대해 상세한 로깅과 함께 적절한 에러 메시지를 반환합니다.
- 재사용성: 여러 서비스에서 공통으로 사용하는 DB 쿼리 로직은 별도 함수나 모듈로 분리하여 재사용합니다.
